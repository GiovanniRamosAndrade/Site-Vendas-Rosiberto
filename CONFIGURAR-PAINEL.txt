ATUALIZAÇÃO PARA CLOUDFLARE WORKERS (workers.dev)

Este pacote foi feito para o Worker "site-vendas-rosiberto". Ele mantém o site
no endereço workers.dev e acrescenta um painel privado. Não use o pacote
anterior de Pages Functions.

1. Envie os arquivos do ZIP ao seu repositório GitHub, mantendo css/, js/ e
functions/. O ZIP NÃO contém js/dados.js, então os produtos existentes ficam.
No repositório, worker.js, wrangler.jsonc e build.sh devem ficar na raiz.

2. No painel Cloudflare, abra Workers & Pages > site-vendas-rosiberto >
Settings > Build (ou Builds). Confirme que o GitHub está conectado à branch
main. Configure Build command = sh build.sh e Deploy command = npx wrangler
deploy. Salve e faça um deploy. O build.sh cria a pasta dist; não a envie ao
GitHub. A configuração wrangler.jsonc aponta para esse dist.

3. Gere uma chave privada: depois do deploy, abra
https://site-vendas-rosiberto.ramosgiovanni025.workers.dev/admin.html,
expanda "Primeira configuração: gerar uma chave" e clique em "Gerar chave
segura". Copie a chave hexadecimal e guarde o link privado mostrado na tela.

4. No GitHub, em Settings da SUA CONTA > Developer settings > Personal access
tokens > Fine-grained tokens, crie um token com acesso SOMENTE ao repositório
GiovanniRamosAndrade/Site-Vendas-Rosiberto. Em Repository permissions, dê
Contents = Read and write. Copie o token na criação e anote sua expiração.

5. Na Cloudflare, abra Workers & Pages > site-vendas-rosiberto > Settings >
Variables and Secrets > Add. Crie DOIS itens com Type = Secret:
   Name: PUBLISH_KEY  Value: chave hexadecimal do passo 3
   Name: GITHUB_TOKEN  Value: token do GitHub do passo 4
Salve/Deploy as alterações. Nunca cole esses valores em arquivos no GitHub.

6. Abra o link privado do passo 3, edite um card, salve e clique em "Publicar
agora". O painel cria um commit de js/dados.js no GitHub. Espere o deploy
automático do Worker e confira a vitrine em outra janela. O cliente só precisa
do link privado para publicar; não precisa entrar no GitHub.

Quem tiver o link privado poderá publicar. Para revogar, troque PUBLISH_KEY
no Worker e gere outra chave. Se o token do GitHub vencer, crie outro e troque
GITHUB_TOKEN. Fotos selecionadas do aparelho ficam dentro de js/dados.js e
podem aumentar o arquivo; use URLs de imagens para muitos produtos.

Se o site não estiver conectado ao GitHub em Settings > Build/Builds, conecte
esse repositório primeiro. O Worker deve ter exatamente o nome indicado em
wrangler.jsonc. Se você usou a versão sem pastas, ajuste GITHUB_DATA_PATH e
build.sh; esta atualização pressupõe css/ e js/.

Depois de editar, clique em Publicar agora. O painel cria um commit no GitHub e a Cloudflare atualiza a vitrine após o deploy. O rascunho continua salvo neste navegador.

O link privado permite publicar sem entrar no GitHub. Não o envie a visitantes. Para editar em outro aparelho, abra o link privado lá; use o backup JSON para transferir rascunhos ainda não publicados.

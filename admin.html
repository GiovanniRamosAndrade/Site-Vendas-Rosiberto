Salvar e publicar

O rascunho fica salvo neste navegador. Para atualizar a vitrine publicada, baixe dados.js e substitua o arquivo antigo dentro da pasta js na hospedagem. Envie esse arquivo ao responsável pela hospedagem se necessário.

Este painel não possui login nem servidor. Abrir o painel em outro aparelho não leva o rascunho junto; use o backup JSON para transferir. A troca de dados.js atualiza o site para todos.
